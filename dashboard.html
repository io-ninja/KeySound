Akses keyboard & privasi
  1. Buka System Settings → Privacy & Security → Input Monitoring. Izinkan aplikasi peluncur atau Python. Periksa juga Accessibility bila perlu. Setelah mengubah izin, restart service; menunggu saja belum tentu cukup.
  2. Jalankan KeySound setelah login Windows pada sesi desktop Anda. Tidak perlu izin Accessibility macOS. Untuk autostart gunakan windows.ps1 melalui Task Scheduler, bukan Windows Service. Layar login/UAC dan aplikasi dengan pembatasan input dapat tidak terjangkau.
  3. Listener hanya memakai kode tombol untuk memilih audio. Windows menyimpan set tombol yang sedang ditahan untuk menolak pengulangan, lalu menghapusnya saat dilepas. Tidak ada pencatatan isi ketikan, riwayat tombol, atau pengiriman tombol ke dashboard.
  4. Secure Input pada kolom kata sandi atau aplikasi tertentu dapat menghentikan suara. KeySound tidak mencoba melewati perlindungan itu.
  5. Label mengikuti posisi keyboard ANSI. Tombol media/Fn tertentu bergantung pada perangkat dan sistem operasi. Menutup tab tidak menghentikan service; tombol Matikan suara hanya membisukan audio.
